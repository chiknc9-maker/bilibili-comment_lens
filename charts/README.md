# 两张结构化图（数据 + 生成脚本）

给专栏配图用。**图里不含用户名、不含逐字引文、不含 `[T序号]`**，只有转述与类型标签，
公开分享符合 README 的脱敏规则。

| 文件 | 是什么 |
| --- | --- |
| `battlelines.png` | 图一：四条争论的战线（1280×1471）——左右两极为立场，中缝标「分歧」 |
| `gestures.png` | 图二：六种「姿势」表（1280×1434）——每类在争论里干什么、有没有被埋掉的内核 |
| `battlelines.json` / `gestures.json` | 图的**全部内容**（文字、标签、计数、脚注）都在这里 |
| `*.csv` | 同一份数据的表格版，UTF-8 带 BOM，Excel 双击不乱码 |
| `make_charts.py` | 读 JSON → 画 PNG + 导出 CSV（Pillow，无其他依赖） |

## 改完再画一次

```powershell
.venv\Scripts\python.exe charts\make_charts.py
```

只改文字/增删条目时改 JSON 即可，**不用重画**。想换宽度或配色，改 `make_charts.py`
顶部的 `W`、`MARGIN` 与颜色常量。

## 数据从哪来

两图内容都取自 `reports/BV1iUXNBzEVh_report.md`（九段式报告）：

- 图一 = 第三节「观点地图」的 6 个观点簇（P1~P6）+ 8 组簇间关系 + 4 个核心分歧（`battlelines.json`）
- 图二 = 第六节「非论证表达解剖」的 6 簇（`gestures.json`）

## 字段说明

`battlelines.json`

| 字段 | 含义 |
| --- | --- |
| `lines[].no` / `question` / `level` | 战线序号、争的那个问题、涉及的层次（事实/概念/价值/规范） |
| `lines[].left` / `right` | 两极：`stance` 立场名、`points` 一句话要点、`clusters` 对应观点簇 |
| `lines[].right.implicit` | 可选：这一极是**隐含**的（没有评论正面论证），图上会加一行小字说明 |
| `footer.facts` / `note` | 底部事实带：8 组关系的分布 + 一条「看似冲突其实不在同一层」的说明 |

`gestures.json`

| 字段 | 含义 |
| --- | --- |
| `rows[].name` | 姿势名（报告里的簇标题） |
| `rows[].kinds` / `seen` | 类型标签（one_liner / irony / emotion / question / meme / other）与出现次数 |
| `rows[].literal` / `does` | 字面在说什么；在争论里实际干了什么活 |
| `rows[].kernel.has` / `text` | 有没有被埋掉的内核；`false` 时统一写「已确认过，不是没找」 |

## 建议插入位置（对应新版全文）

1. **图一**放在「一层一层往下拆」之前——先让读者看到「吵了 100 条，其实只有四条战线」，
   再进入具体解剖；
2. **图二**放在第二层（「有些垃圾里埋着真问题」）讲完三类之后——读者的「哦原来还有这种」
   刚好被表格收口。

## 已知取舍

- 文字密度按「专栏内点开放大」设计；1280px 宽、正文 18px，在图内直接读偏小，
  点开后清晰。若要做**不用点开也能读**的版本，得把每条战线拆成一张图（4 张），
  或者牺牲要点字数；
- 图二「出现 N 处」是报告里该簇列出的引用条数，合计 27 处，而解剖素材是 30 条，
  差额是少量重复引述——两处差异都已在图脚注明，不做四舍五入掩盖。
